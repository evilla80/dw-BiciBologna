# Data Warehouse — BiciBologna

Il progetto organizza e trasforma dati relativi al bike sharing e alla mobilità ciclistica attraverso una pipeline di dati e un modello analitico. Include componenti per l'estrazione, il caricamento, l'esportazione, la modellazione con dbt e la visualizzazione tramite dashboard.

Progetto d'esame di Large Scale and Data Management.

## Struttura della repository

- `01_extraction/` — componenti per l'estrazione dei dati.
- `02_load/` — componenti per il caricamento dei dati.
- `04_export/` — componenti per l'esportazione.
- `bike_sharing_dbt/` — progetto di modellazione dati con dbt.
- `dashboard/` — dashboard per la consultazione dei risultati.
- `pipeline.py` — script della pipeline.
- `test_finale.py` — script di test.
- `img/` — immagini e materiali del progetto.
- `docs/` — documentazione del progetto, inclusi il modello ODS e la documentazione logica.

## Tecnologie

Il progetto utilizza Python, dbt e strumenti per la gestione e la visualizzazione dei dati. Informazioni aggiuntive si trovano nella documentazione del progetto.
